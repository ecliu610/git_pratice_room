# git_pratice_room
This repository is for practicing Git commands and workflows.

League of Legends characters, known as champions, each have unique abilities, personalities, and roles that shape how every match is played. From durable tanks and strategic supports to high-damage assassins and mages, these characters create a wide variety of team compositions and playstyles that keep the game dynamic and competitive.

## League Rift Tetris
A playable Tetris game with League-themed champion effects is included in this branch.

### Run
1. Run `npm start`
2. Open `http://localhost:3000`
